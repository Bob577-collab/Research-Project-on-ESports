Computer components

What are They? Computer hardware determines how fast your computer performs and executes functions. In ESports this is crucial so players need to pick the right components in their computers. The main components that are important in gaming are the central processing unit, the graphics processing unit, the memory, and the motherboard.

How it relates to CS: Computer science is a tool that allows us to study computer components and choose the rigt pc build. This is very helpful for gamers that want to optimize speed,performance,quality and their gameplay.

Programming

What is it: Programming is the process of giving step-by-step instructions to a computer using specialized languages that are called programming languages. These languages are decoded by the computer into machine code and processed by the CPU. Video games are built primarily by programming languages in game engines so these languages are extremely important.

How it relates to CS: Computer science focuses heavily on programming and learning different languages to make the computer execute taks. For a game studio to produce games, skilled programmers need to be hired and proficiently use various programming languages to code the games.

Programming Languages: C++, C#, and C are the primary languages for coding games since they can directly manage memory and communicate with the computer hardware.
